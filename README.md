## 📌 Project Overview

The Banking Transaction System is a Java-based application designed to manage banking operations, including account management, deposits, withdrawals, and transaction history.

This project focuses on Software Quality Assurance through manual testing, automation testing, API testing, static testing, and Jira test management.

## 🎯 Project Objectives

- 🏦 Verify account management functionality.
- 💰 Validate deposit and withdrawal operations.
- 🔍 Identify invalid transactions and edge cases.
- 🛡️ Verify exception handling.
- 📊 Ensure transaction history accuracy.
- 🧪 Apply manual and automated testing techniques.
- 🐞 Identify and track defects using Jira.
- ✅ Ensure application behavior matches requirements.
